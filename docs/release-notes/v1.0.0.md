LinguaPDF 是一个免费、开源、完全离线的 PDF 阅读与语言练习工具，面向大型扫描教材：可以直接在页面上填写答案、手写标记，并查词、朗读、OCR。这是第一个正式版本，仅提供 Windows x64 版。

## 下载与运行

1. 下载 `LinguaPDF-1.0.0-windows-x64.zip`，可以用同名的 `.sha256` 文件核对散列：
   ```powershell
   (Get-FileHash .\LinguaPDF-1.0.0-windows-x64.zip -Algorithm SHA256).Hash
   ```
2. 把整个 ZIP **解压**到任意目录（不要直接在压缩包里运行，也不要只复制 exe），双击 `LinguaPDF.exe`。
3. 程序没有代码签名。首次运行如果 Windows 提示“Windows 已保护你的电脑”，点 **更多信息 → 仍要运行**。

要求：Windows 10/11 x64，支持 Direct3D 11 的显卡。不需要安装、管理员权限、网络或账号。

## 主要功能

- **阅读**：上千页扫描教材也能流畅滚动和缩放；支持双页布局、缩略图、书签，浅色、纸张色、深色主题。
- **填写**：单击页面任意位置输入答案；悬停在教材的横线或虚线上可以直接在线上作答；可改颜色、字号、粗细和斜体。
- **手写**：多色画笔（带平滑和笔锋）和橡皮擦，按住右键临时擦除；统一撤销和重做。
- **语言工具**：复制原文；离线 OCR（法、英、简中）；英汉和法语离线词典，法语支持变形还原和常用时态变位表；法语自然朗读（男声/女声，可调语速）。
- **保存与导出**：自动保存，可从异常退出中恢复；导出带答案和笔迹的新 PDF，原文件不会被修改。

完整更新内容见 [CHANGELOG.md](https://github.com/daodreamer/pdf_editor_for_learning_language/blob/v1.0.0/CHANGELOG.md)。

## 从 0.1.0 测试版升级

产品已更名为 LinguaPDF。删除旧的解压目录，解压新版本即可。首次启动时，练习数据会自动从 `%LOCALAPPDATA%\Langlern\Langlern` 迁移到 `%LOCALAPPDATA%\LinguaPDF`。

## 已知限制

- 没有代码签名，会出现上面提到的 SmartScreen 提示。
- 暂无 macOS 版。
- 导出的答案字体只覆盖随附 Noto Sans SC 支持的字符。
- OCR 结果可能有误。
