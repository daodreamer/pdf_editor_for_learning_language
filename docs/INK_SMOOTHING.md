# 自由画笔平滑与设置验证（2026-10-17）

本次范围：改善已有自由画笔的颜色/粗细入口与曲线质量，不新增画布或图层系统。

## 行为与兼容性

- 自动、书写模式右上方的“画笔 · … pt”打开设置；书写工具也可开关设置面板。
- 粗细范围 0.5–16 PDF pt，步进 0.5 pt；六种预设色与系统自选颜色对话框。设置面板提供颜色选中标记、数值和粗细预览。
- 中点二次 Bézier 平滑、按屏幕误差细分、物理像素抗锯齿羽化边缘、圆端点与回折连接。只更新笔尾受影响分块。
- 保存仍为原始 PDF 坐标采样点；旧数据可读取，旧折线也将使用平滑外观。显示、擦除/移动命中、矢量 PDF 导出共享同一曲线。
- 起笔后固定该笔颜色/宽度，不对已有笔迹追溯修改样式。调整设置无需 PDF 解码。

## 复现与证据

Windows 11 x64，Intel Core Ultra 7 265K，NVIDIA RTX 5070 / D3D11，DPR 1.5；Qt 6.8.3、PDFium 157.0.8100.0、MSVC x64 Release。修改前基线提交 `4c2ba8bb6182dcd3bdcc5de3a3e0e51122148e33`，工作树当时干净。

```powershell
./tools/build-windows.ps1 -Test -Lint
.tools/venv/Scripts/python benchmarks/run-ink.py --run benchmarks/results/<新的目录> --repeat 3
```

每轮向真实 QML 窗口注入 8192 个移动事件，每 64 事件让出事件循环并等待 8 ms；扫描样例 `tests/fixtures/scan.pdf`，输入/源码/二进制 SHA-256、原始事件与帧间隔留在各轮目录。修改前结果位于 `benchmarks/results/ink-smooth-before-20261017/`；修改后结果位于 `benchmarks/results/ink-smooth-after-20261017/`。

`frameSwapped` 是 Qt 帧提交代理，不是硬件输入到显示延迟。CPU 内存为系统工作集/私有字节；不以几何大小推算 GPU 显存。三轮顺序采样仅用于本机回归比较，不作稳定 60 FPS 或更低笔延迟声明。

## 验证边界

实际执行：Release 构建成功；完整 CTest 8/8 组通过（52.92 s），其中笔迹套件 11 项通过。移除颜色对话框的多余默认枚举配置后再次构建，qmllint 无警告；最终二进制重跑设置/像素与导出用例通过。大文件与长期压力的 opt-in 用例仍按原规则跳过，不计作验收通过。

证据目录 `benchmarks/results/ink-smooth-verified-20261017/`：浅色真实窗口 `smooth-ink.png`、`pen-settings.png`；`dpi3/` 是设置 `QT_SCALE_FACTOR=2` 的附加像素回归（系统 DPR 1.5，合成 DPR 3；不是物理跨屏验证）。MuPDF 独立回读真实 `annotated.pdf` 与 `sparse.pdf`，8 页内容/文字/字体/旋转检查通过，7 页未修改内容保持一致，原文件散列不变；已目视检查导出曲线。验证脚本统一忽略文字提取中由字体/格式分段产生的空白，保留 Unicode 文本断言。

回归覆盖曲线端点、连接切线与凸包范围、曲线命中擦除及撤销、0.5 pt 和预设色传入画笔、面板背景拖动/右键拦截、跨 128/256 点边界增量显示与整笔重建像素一致，以及真实曲线 PDF 导出。

没有新增产品依赖。macOS/Metal、物理数位笔手感、原生系统颜色对话框人工点击、硬件端到端延迟、GPU 显存、sanitizer 和长期压力本轮未验证。压感、预测输入和可调稳定器未实现，不宣称已达到 Procreate 的等效笔刷效果。
