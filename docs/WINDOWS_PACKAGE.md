# Windows 候选包使用说明

本应用动态使用 Qt 6.8.3（LGPL-3.0-only 选项）、PDFium 157.0.8100.0（随包宽松许可证及通知）和 Noto Sans SC（OFL）。项目 MIT 不覆盖这些组件，完整文本与源码位置见 `licenses/`。

解压整个目录，双击 `langlern.exe`。无需 Qt SDK、Python 或联网；不要只复制 exe。此包为未签名的 Windows x64 本地候选包。

打开 PDF 后，使用页码、滚轮、缩放及模式工具栏。自动模式可在空白处输入、拖动选择原文；画笔和整笔橡皮擦有专用模式。F1 查看完整快捷键。文字框未选中时透明无边框。

练习异步自动保存；关闭、换文档时等待提交。请检查底部保存/错误状态。导出选择一个尚不存在的新 PDF 文件名；原文档不会被覆盖。导出字体暂限随附 Noto Sans SC 支持的字符。

更新：退出程序，将新版本解压到新目录运行；不要覆盖运行中的 DLL。原 PDF 和本机练习数据继续保留。卸载：退出后删除解压目录即可。练习数据默认位于 `%LOCALAPPDATA%/Langlern/Langlern/workspaces`，删除程序目录不会删除它；清理练习前先备份这个目录和原 PDF。若设置 `LANGLERN_WORKSPACE_DIR`，以设置路径为准。

`manifest.json` 记录包内文件与源码 SHA-256；`source.zip` 是本候选包实际使用的项目源码（含未提交修改），含构建脚本和依赖锁文件。`licenses/` 提供 Qt、PDFium、字体、runtime 通知及对应源码位置。兼容的 Qt 动态库可以替换；本项目不限制许可证允许的修改、调试或逆向工程。

已测范围与限制见 `source.zip` 内 `docs/PHASE8_REPORT.md`。开发机清理 SDK 搜索路径验证不等同于干净 Windows 虚拟机验收；系统 IME、真实触控笔/触控板、跨屏、冷启动和远程 CI 仍需要对应设备或环境。macOS 按用户安排留待项目完成后运行。当前不作为已完成安全与许可发布审批的正式公开发行版。
