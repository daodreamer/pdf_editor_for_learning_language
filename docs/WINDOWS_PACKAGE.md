# LinguaPDF 1.0.0（Windows x64）使用说明

LinguaPDF 是免费、开源、完全离线的 PDF 阅读与语言练习工具。本文件随发行包分发，包内文件名为 `README.md`。

## 运行

1. 把整个压缩包解压到任意目录，双击 `LinguaPDF.exe`。不要只复制 exe，程序需要同目录下的其他文件。
2. 程序没有代码签名。首次运行如果 Windows 提示“Windows 已保护你的电脑”，点 **更多信息 → 仍要运行**。
3. 运行时不需要安装、管理员权限、网络或账号。要求 Windows 10/11 x64，显卡支持 Direct3D 11。

## 基本操作

- **打开**：点击“导入”，或把 PDF 拖进窗口。原文件只读取，不会被修改。
- **工具**：A 自动、P 书写、T 打字、C 批改、R 点读、E 橡皮（输入框有焦点时，这些快捷键不会被占用）。F1 查看全部快捷键。
- **填写**：自动模式下，在空白处单击即可输入；悬停在横线或虚线上可以直接在线上作答。Ctrl+Enter 完成，Tab 在本页答案之间切换。
- **手写**：在空白处拖动书写；按住右键可临时擦除。
- **选字、查词、朗读**：拖动选择原文，或双击后第二次按住拖动；选区上方有“复制、朗读”按钮。双击单词查词。扫描页会按需离线识别文字，可在“··· → OCR 与朗读设置”里换识别语言、选择法语男声或女声、调整语速。
- **撤销/重做**：Ctrl+Z / Ctrl+Y。

## 保存、导出与数据

- 练习进度会自动保存。关闭或切换文档时，程序会等待保存完成。请留意底部的保存状态。
- “导出”会生成一个**新的** PDF，必须选一个尚不存在的文件名，原文件不会被覆盖。
- 练习数据位于 `%LOCALAPPDATA%\LinguaPDF`。删除程序目录不会删除练习数据。如需清理，先备份这个目录和原 PDF。

## 更新与卸载

- **更新**：退出程序，把新版本解压到新目录后运行。练习数据会保留。从 0.1.0 测试版（Langlern）升级时，首次启动会自动把 `%LOCALAPPDATA%\Langlern\Langlern` 迁移过来。
- **卸载**：退出程序后删除解压目录即可；练习数据需要另外手动删除。
