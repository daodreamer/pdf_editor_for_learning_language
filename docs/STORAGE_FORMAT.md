# 本地练习工作区（schema 1）

阶段 7，2026-10-15。Windows 已验证；macOS 实机按用户安排延期。

## 身份与目录

正式入口使用 `QStandardPaths::AppLocalDataLocation/workspaces`，Windows 通常为 `%LOCALAPPDATA%/Langlern/Langlern/workspaces`。`LANGLERN_WORKSPACE_DIR` 只用于指定其他本地目录或隔离测试，不依赖原 PDF 目录可写。

原 PDF 全内容 SHA-256 为身份，文件名为 `<sha256>.json`。身份校验在低优先级文件线程完成，首屏不等待，但练习编辑等待恢复完成；阅读/滚动保持可用。移动或复制相同内容可恢复同一工作区；内容不同使用独立工作区，不自动迁移答案。`path-<路径散列>` 仅记录路径上次身份以提示内容变化，不作为恢复依据；未实现相似文档重关联。

同内容文档共享工作区，由 `<sha256>.json.lock` 的 `QLockFile` 排他占用。其他进程占用时只读提示，解决冲突后重新打开。依赖 Qt 对已死亡本机进程的 stale lock 检测；不按超时强行抢活跃锁，不支持网络共享盘的分布式写入。

## 编码与数据

UTF-8 JSON 外层包含 `schema: 1`、`identity`、字符串 `revision`、UTF-8 JSON 字符串 `payload`、payload 的 `sha256`。数字字段和点列校验有限范围；ID 必须为非空且不重复的 UUID。散列用于完整性/身份检查，不是防篡改签名或加密。

payload 包含 notes 与 ink：

| 字段 | 含义 |
| --- | --- |
| notes.id / page | UUID，零起始页号 |
| notes.anchor / right / down | PDF 原始页面坐标及正交单位方向，保留 CropBox、固有旋转与 UserUnit 契约 |
| notes.width / height / size | 原始页面单位中的框宽高与字体大小；高度随编辑器内容扩展 |
| notes.text / family / color | 已提交文字（不含 IME preedit）、受控 Noto Sans SC、`#AARRGGBB` |
| notes.widthLocked | 可选布尔值；新建为 false，仅手动 resize 设为 true。换行和到达页边不再自动锁宽。缺失时按 true 读取以保留旧答案版式；删除文字时解除锁宽，以原宽度为自动换行上限 |
| notes.minimumHeight | 可选正数，缺失为 24；用户手动调整的高度下限，实际框高还会为完整文字排版扩展 |
| notes.maximumWidth | 可选非负数，缺失/0 表示使用页面剩余宽度；横线创建的答案以横线宽度为上限。删减文字时可缩小实际框宽/高，minimumHeight 恢复为 24；手动 resize 会清除此上限 |
| notes.styles | 可选有序数组，缺失为空；start/length 为纯文字 UTF-16 区间，size 为 8–72 整数字号，color 为 #AARRGGBB，bold/italic 为布尔值。区间不能重叠或越界；不保存 HTML、图片或外部资源 |
| notes.order | 字符串创建序号；文字内部叠放顺序 |
| ink.id / page / points | UUID、页号、PDF 原始点列；不保存视口像素 |
| ink.width / color / order | 原始单位笔宽、`#AARRGGBB`、字符串创建序号 |

文字层在笔迹层之上；两类内部按创建序号恢复和导出。视口、选中态、IME 预编辑、在途笔迹/移动及撤销历史不持久化；擦除在途快照仍保留未提交前的笔迹。关闭前提交 IME 并结束文字事务，取消未完成手势。

保护上限：64 MiB 编码文件、100000 个标注、总计 2000000 个笔迹点、单笔 65536 点、单框 1000000 UTF-16 单元、最多 65534 个不同导出字形/Unicode 映射。超限保存/恢复/导出明确失败，保留现有文件和当前编辑，不静默截断。大文本/点缓冲区跨线程隐式共享，JSON 编解码及磁盘写入在文件线程；GUI 仍需复制标注记录列表，不宣称任意标注量均无成本。

## 保存、备份与恢复

编辑后 750 ms 去抖，连续输入最长每 5 s 调度一次；在途保存完成后有新修订会继续保存。间隔是调度策略，不保证磁盘在 5 s 内完成。只有对应修订真正提交成功才显示“已保存”。Ctrl+S 立即调度；导出注明独立快照修订。

每次先验证当前主文件，再用禁止直接写回退的 `QSaveFile` 原子更新 `.bak` 为前一个有效版本，之后原子提交主文件。临时写入失败/取消不替换主文件；备份失败则不替换主文件。正常关闭/切换等待异步保存成功；失败留在原文档，修复权限或空间后再保存/关闭重试。

主文件损坏时读取有效备份，先把损坏主文件重命名为唯一 `.corrupt-UUID` 证据，再允许保存；不能保留证据则禁止写入。主文件缺失可用备份恢复。无法恢复或版本不支持时禁止写入，不以空模型覆盖；已有未来主版本即使备份可读也不替换。手动恢复前应先复制整个工作区；不要在应用持锁时修改快照。

异常结束只能恢复最后成功落盘修订。尚未调度/提交的输入、IME preedit、在途手势可能丢失。进程强杀、部分临时文件写入和真实文件提交失败已测试；未模拟真实断电、控制器缓存丢失或把系统磁盘填满，不承诺断电零丢失。

## PDF 导出

唯一 PDFium 线程打开独立原 PDF 会话，校验内容身份；Qt 排版提供字形与基线，PDFium 嵌入 OFL Noto 字体、显式 Unicode 映射并添加原生文字。笔迹由既有 Qt Gui 的 QPdfWriter 生成为透明矢量层，再由 PDFium 导入。未整本栅格化，未修改页保留原内容流。

输出写到目标目录临时文件，回读页数、再次验证原 PDF 散列，最后以不替换目标的重命名提交。任何已有目标（含原文件、符号链接/硬链接别名）一律拒绝，不提供覆盖开关。失败清理本次临时文件，保留原 PDF 和练习工作区。导出期间可继续编辑；切换/关闭等待导出结束。单个 PDFium 保存调用不可抢占，阅读后台任务可能暂时等待，GUI 不同步等待。

字体完整压缩嵌入一次，当前约增加 6 MiB；不支持的字符（例如当前字体没有的 emoji）明确使导出失败。PDFium 字体/CID 与 form import 为锁定版本公开 experimental API，升级必须重跑实际文件回归。新增内容固化于 PDF，不保证第三方阅读器可再编辑为练习框。
