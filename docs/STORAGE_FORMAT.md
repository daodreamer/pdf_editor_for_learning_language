# 本地练习工作区（schema 1 / 2）

阶段 7，2026-10-15。Windows 已验证；macOS 实机按用户安排延期。2026-11-28 增加 schema 2（练习轮次），见文末“重做模式与 schema 2”。

## 身份与目录

正式入口使用 `QStandardPaths::AppLocalDataLocation/workspaces`，Windows 通常为 `%LOCALAPPDATA%/Langlern/Langlern/workspaces`。`LANGLERN_WORKSPACE_DIR` 只用于指定其他本地目录或隔离测试，不依赖原 PDF 目录可写。

原 PDF 全内容 SHA-256 为身份，文件名为 `<sha256>.json`。身份校验在低优先级文件线程完成，首屏不等待，但练习编辑等待恢复完成；阅读/滚动保持可用。移动或复制相同内容可恢复同一工作区；内容不同使用独立工作区，不自动迁移答案。`path-<路径散列>` 仅记录路径上次身份以提示内容变化，不作为恢复依据；未实现相似文档重关联。

同内容文档共享工作区，由 `<sha256>.json.lock` 的 `QLockFile` 排他占用。其他进程占用时只读提示，解决冲突后重新打开。依赖 Qt 对已死亡本机进程的 stale lock 检测；不按超时强行抢活跃锁，不支持网络共享盘的分布式写入。

## 编码与数据

UTF-8 JSON 外层包含 `schema`（1 或 2，见下文）、`identity`、字符串 `revision`、UTF-8 JSON 字符串 `payload`、payload 的 `sha256`。数字字段和点列校验有限范围；ID 必须为非空且不重复的 UUID。散列用于完整性/身份检查，不是防篡改签名或加密。

payload 包含 notes 与 ink：

| 字段 | 含义 |
| --- | --- |
| notes.id / page | UUID，零起始页号 |
| notes.anchor / right / down | PDF 原始页面坐标及正交单位方向，保留 CropBox、固有旋转与 UserUnit 契约 |
| notes.width / height / size | 原始页面单位中的框宽高与字体大小；高度随编辑器内容扩展 |
| notes.text / family / color | 已提交文字（不含 IME preedit）；字体组只接受 `Langlern Sans + Kai`（2026-11-23 起新建答案）或 `Noto Sans SC`（此前的答案，保持原样）；`#AARRGGBB` |
| notes.widthLocked | 可选布尔值；新建为 false，仅手动 resize 设为 true。换行和到达页边不再自动锁宽。缺失时按 true 读取以保留旧答案版式；删除文字时解除锁宽，以原宽度为自动换行上限 |
| notes.minimumHeight | 可选正数，缺失为 24；用户手动调整的高度下限，实际框高还会为完整文字排版扩展 |
| notes.maximumWidth | 可选非负数，缺失/0 表示使用页面剩余宽度；横线创建的答案以横线宽度为上限。删减文字时可缩小实际框宽/高，minimumHeight 恢复为 24；手动 resize 会清除此上限 |
| notes.lineSpacing | 可选非负数，PDF 单位，缺失/0 表示字体默认行距（旧文件兼容）。多行填写线块创建的整体答案保存印刷横线的行距：首行基线位置与单行答案相同，其后每行（自动换行或 Enter）下移一个行距落在下一条横线上；编辑器、尺寸计算与导出共用同一行距规则。此类答案删减文字时不缩小到低于整块高度 |
| notes.styles | 可选有序数组，缺失为空；start/length 为纯文字 UTF-16 区间，size 为 8–72 整数字号，color 为 #AARRGGBB，bold/italic 为布尔值。区间不能重叠或越界；不保存 HTML、图片或外部资源 |
| notes.order | 字符串创建序号；文字内部叠放顺序 |
| ink.id / page / points | UUID、页号、PDF 原始点列；不保存视口像素 |
| ink.width / color / order | 原始单位笔宽、`#AARRGGBB`、字符串创建序号 |

文字层在笔迹层之上；两类内部按创建序号恢复和导出。视口、选中态、IME 预编辑、在途笔迹/移动及撤销历史不持久化；擦除在途快照仍保留未提交前的笔迹。关闭前提交 IME 并结束文字事务，取消未完成手势。

选择框标记（2026-11-23）是普通 ink 记录（✓ 一笔、✗ 两笔，无 pressure），不增加字段。新答案的默认颜色写入既有 `notes.color`，默认加粗/倾斜写入既有 `notes.styles`。

紧凑虚线答案复用现有字段：基础 size 为 9、minimumHeight 为 14 PDF pt，不增加快照版本。删除文字时，紧凑答案回到 14 pt 最小高度，普通答案仍为 24 pt；实际内容高度继续参与排版。旧快照读取规则不变。

保护上限：64 MiB 编码文件、100000 个标注、总计 2000000 个笔迹点（两项均按整个文件计，含 schema 2 的所有历史轮次）、单笔 65536 点、单框 1000000 UTF-16 单元、最多 65534 个不同导出字形/Unicode 映射。超限保存/恢复/导出明确失败，保留现有文件和当前编辑，不静默截断。大文本/点缓冲区跨线程隐式共享，JSON 编解码及磁盘写入在文件线程；GUI 仍需复制标注记录列表，不宣称任意标注量均无成本。

## 保存、备份与恢复

编辑后 750 ms 去抖，连续输入最长每 5 s 调度一次；在途保存完成后有新修订会继续保存。间隔是调度策略，不保证磁盘在 5 s 内完成。只有对应修订真正提交成功才显示“已保存”。Ctrl+S 立即调度；导出注明独立快照修订。

每次先验证当前主文件，再用禁止直接写回退的 `QSaveFile` 原子更新 `.bak` 为前一个有效版本，之后原子提交主文件。临时写入失败/取消不替换主文件；备份失败则不替换主文件。正常关闭/切换等待异步保存成功；失败留在原文档，修复权限或空间后再保存/关闭重试。

主文件损坏时读取有效备份，先把损坏主文件重命名为唯一 `.corrupt-UUID` 证据，再允许保存；不能保留证据则禁止写入。主文件缺失可用备份恢复。无法恢复或版本不支持时禁止写入，不以空模型覆盖；已有未来主版本即使备份可读也不替换。手动恢复前应先复制整个工作区；不要在应用持锁时修改快照。

异常结束只能恢复最后成功落盘修订。尚未调度/提交的输入、IME preedit、在途手势可能丢失。进程强杀、部分临时文件写入和真实文件提交失败已测试；未模拟真实断电、控制器缓存丢失或把系统磁盘填满，不承诺断电零丢失。

## PDF 导出

唯一 PDFium 线程打开独立原 PDF 会话，校验内容身份；Qt 排版提供字形与基线，PDFium 嵌入 OFL Noto 字体、显式 Unicode 映射并添加原生文字。笔迹由既有 Qt Gui 的 QPdfWriter 生成为透明矢量层，再由 PDFium 导入。未整本栅格化，未修改页保留原内容流。

输出写到目标目录临时文件，回读页数、再次验证原 PDF 散列，最后以不替换目标的重命名提交。任何已有目标（含原文件、符号链接/硬链接别名）一律拒绝，不提供覆盖开关。失败清理本次临时文件，保留原 PDF 和练习工作区。导出期间可继续编辑；切换/关闭等待导出结束。单个 PDFium 保存调用不可抢占，阅读后台任务可能暂时等待，GUI 不同步等待。

字体完整压缩嵌入一次，当前约增加 6 MiB；不支持的字符（例如当前字体没有的 emoji）明确使导出失败。PDFium 字体/CID 与 form import 为锁定版本公开 experimental API，升级必须重跑实际文件回归。新增内容固化于 PDF，不保证第三方阅读器可再编辑为练习框。

## 重做模式与 schema 2（2026-11-28）

### 隐藏答案（只影响显示，不进文件）

`H` 隐藏或显示当前页答案，`Shift+H`（macOS 显示为 ⇧H）隐藏或显示全书；也可在“··· → 隐藏本页答案 / 隐藏全书答案”或“本页练习”面板操作。它们与 A/P/T/C/R/E 工具键一样是单键快捷键，正在编辑文字时不响应；不使用 ⌘H（macOS 的“隐藏应用”），`Ctrl/⌘+Shift+字母` 已被模式切换占用。

实现为每页一条“遮罩水位”：隐藏时记下文字和笔迹的下一个创建序号（`order`），序号低于水位的内容不显示、不参与任何命中（橡皮、移动笔迹、选择框切换、批改、Tab 切换答案、横线提示的“已有答案”判断）；批改标记跟随它的答案。隐藏不修改 notes/ink、不进撤销历史、不增加保存修订、不请求 PDF 渲染。遮罩只在本次会话有效，关闭文档后答案恢复显示，不写入快照。被隐藏的页面顶部显示“已隐藏 N 处答案 · 按 H 显示”。

撤销/重做如果增删了某页被隐藏的内容，会先显示该页并提示，不在不可见处生效。

**隐藏期间新写的内容**：在被隐藏的页面上第一次作答（新建文字答案、书写笔迹或勾选印刷选择框）时，自动为该页开始新一轮：被隐藏的答案归档为一轮，页面遮罩解除。归档单独占一个撤销步骤：撤销一次只去掉刚写的内容，再撤销一次旧答案回到当前轮（并且可见）。只隐藏不作答不会归档任何内容。

**导出默认包含被隐藏的答案**：隐藏只是视图状态，答案仍是当前数据；用户忘记自己隐藏过时，导出不应悄悄少掉答案。导出前的确认浮层写明“导出每页当前轮……归档的历史练习轮次不导出”；有隐藏内容时显示“包含已隐藏的答案（N 处）”开关，默认打开，关闭后这些答案不进入导出文件但仍保存在本机。

### 练习轮次

“··· → 练习轮次…”面板（“本页练习”面板也有入口）列出本页当前轮与历史轮次（归档时间、答案数、✓/× 数、笔迹数）：

- **开始新一轮**：本页当前全部答案（文字、批改标记、笔迹）移入一条新轮次，页面清空。“全书开始新一轮…”经确认后为每个有答案的页各归档一轮，共享同一个 `batch`，整体是一个撤销步骤。
- **对照**：所选轮次以约 30% 不透明度叠加在页面上（笔迹为独立 InkItem，文字为只读 Text），不可命中、不进入数据、不触发 PDF 解码；删除该轮或关闭文档时取消。叠加文字不还原局部样式（颜色/字号区间），只作对照。
- **恢复**：当前答案非空时先归档为新一轮，再把所选轮次复制为当前轮（新 UUID 与新创建序号，批改标记随答案改名）；历史本身不变。复制前检查整个文件的容量上限，超限时明确报错、不做任何修改。
- **删除**：需二次点击确认；本次会话内可撤销，关闭文档后不可恢复。

撤销命令只记录“哪些轮次被归档/删除”。轮次的条目列表与命令共享隐式共享的 Qt 容器，不复制，因此全书归档不会超出撤销历史的字节预算而被裁掉；历史仍是线性的，跨越轮次边界按顺序撤回。归档时间在每个工作区内严格递增（同一毫秒内连点时顺延 1 ms）。

### schema 2 编码

外层结构不变，`schema` 为 2，payload 增加 `rounds`：

| 字段 | 含义 |
| --- | --- |
| rounds.id | UUID，在文件内唯一（不与任何标注 ID 重复） |
| rounds.page | 零起始页号；该轮所有 notes/ink 的 page 必须等于它 |
| rounds.archived | UTC 时间，`Qt::ISODateWithMs` 并以 `Z` 结尾；同一页的轮次按时间严格递增排列 |
| rounds.batch | 可选 UUID；全书新一轮的各页轮次共享同一值 |
| rounds.notes / rounds.ink | 与顶层 notes/ink 完全相同的记录与校验；轮次不能为空 |

顶层 `notes`/`ink` 仍是当前轮，导出只读它们。标注 ID 在整个文件中唯一；创建序号在当前轮或单个轮次内唯一（归档条目保留原序号，恢复的副本取新序号）。

### 兼容、升级与备份

- **按需升级**：没有任何轮次时仍写 schema 1（字节格式与以前相同），旧版应用可继续读写；出现第一条轮次时才写 schema 2；删光所有轮次后又写回 schema 1。schema 1 的 payload 不得含 `rounds`，schema 2 必须含非空 `rounds`，否则按损坏处理。
- **旧文件可读**：读取接受 1 和 2；schema 1 读入后没有轮次。
- **未来版本不覆盖**：主文件为 1、2 以外的版本时只读并禁止写入，即使 `.bak` 可读也不替换（原规则不变）。旧版应用遇到 schema 2 主文件，按它已有的规则只读提示，不覆盖。
- **一次性升级副本**：主文件为 schema 1 而本次要写 schema 2 时，先把该 schema 1 文件原样写为 `<sha256>.v1.json`（`QSaveFile`），之后永不覆盖；写入失败则不替换主文件并显示错误。需要回到旧版应用时，可在应用关闭后用它手动替换主文件（会丢失升级后的轮次与新答案）。
- **备份与损坏恢复**：`.bak` 轮换和 `.corrupt-UUID` 证据规则不变；`.bak` 可以是 schema 1 或 2，均可用于恢复。
