证据根目录 `benchmarks/results/phase3-20261015/`，原始运行默认 Git 忽略。30 分钟 robustness 轨迹启动后，最终检查另修正调度计时器截止时间、缓存命中状态文字、Ctrl+像素滚轮方向及无变化的 role 通知；其最终构建用独立重复轨迹验证。长压力构建与最终构建分开记录，不把旧二进制的帧分布当作最终二进制性能。每轮 manifest 保留实际源码/二进制/输入 SHA-256；这是未提交工作区，不冒称已有提交。设备与电源方案见本轮 environment.json。

开发中的 qWait 驱动及 GUI queued 帧间隔受到计时/事件投递影响，保留 smoke 和 precise-smoke 供诊断，不把它们与最终数据作为性能 A/B 优化对比。旧 stress-30min 主动在约 40 秒中止，以修复测试收尾锁的潜在死锁；未算 30 分钟成功。

### 最终帧驱动的五轮分布

真实输入是 839,214,902 bytes / 800 页原创 raw 灰度图像 PDF，先计算散列预热 OS 缓存。每轮独立新进程，表内是**同轮 Qt 提交事件**分布，不是屏幕 scanout 或 OS 输入延迟。原始间隔数组和每秒实际/模型偏移已保留。

| 轮次 | 帧间隔样本 | P95 ms | P99 ms | max ms（含重建） |
| --- | ---: | ---: | ---: | ---: |
| 1 | 7,211 | 16.20 | 17.26 | 225.40 |
| 2 | 10,360 | 6.47 | 7.56 | 204.43 |
| 3 | 10,361 | 6.49 | 7.50 | 203.06 |
| 4 | 10,361 | 6.48 | 7.59 | 203.81 |
| 5 | 10,357 | 6.55 | 7.54 | 212.53 |

五轮均满足本设备/本样本的初拟 60 Hz 帧分位目标（P95≤16.67、P99≤33.33 ms）。第 1 轮有更慢的阶段，不能只报告其余快轮。约 203–225 ms 的 max 包含主动关闭持久化后 hide/release/show 的重建间隔；不将该间隔删去，也不据此证明正常输入没有 >100 ms 停顿。高刷新率完整目标及系统输入到屏幕延迟仍未验收。

首页预览交付范围 12.19–13.83 ms，目标交付 45.42–47.50 ms；其后首提交代理范围分别 14.15–35.33 / 45.72–52.32 ms。仅 5 次、不报告跨打开 P95/P99；不称冷加载或实际首像素呈现。

### 缓存、系统资源与 A/B

最终五轮 CPU 图像采样峰值 127.97 MiB，活跃纹理像素估算峰值 64.00 MiB（均在配置内），最多 4 活跃页。每轮 71–73 次可见需求查找，精确命中约 54.93%–56.16%，降档复用约 16.44%–16.90%；29 次淘汰。GPU 无独立 LRU，不伪造 GPU 命中率。

30 分钟压力的受管图像采样峰值 127.99 MiB；进程 private 首值约 180.44 MiB、末值约 450.12 MiB、采样峰值约 632.68 MiB，working set 峰值约 452.67 MiB。**128 MiB 图像预算不是进程内存上限**。这次运行没有崩溃或应用缓存超额，但不能据此宣布无泄漏；引擎缓存、Qt/分配器及驱动资源仍需分配归因。

同轮 Windows GPU Process Memory 294 条记录中 3 条报告错误，空/错不作零。数值采样峰值 Dedicated 约 154.23 MiB、Shared 23.55 MiB、Total Committed 177.78 MiB；三种指标不相加当额外显存。数据来自旧压力构建，不能冒作最终构建的系统 GPU 峰值。该长运行含计数器以及收尾构建/短窗口回归干扰，不用于宣称最终帧率达标。

A 控制只恢复全 role 通知；同一最终帧驱动下 65 秒得到 P95 6.47 / P99 7.58 ms，private 采样峰值约 415.06 MiB。B 的五轮有环境波动，private 采样峰值约 399.60–444.80 MiB；**未证明 FPS 或内存改善**。保留通知调整是因为它消除了无变化信号，并有直接行为回归，不声称观测到了性能提升。源码快照、独立 manifest 和 notification-control.patch 可追踪 A/B 差异。

### 启动目标未达

startup/：3 次预热 + 30 次新进程，warm OS cache；外部可交互代理 median 378.52 ms、P95 396.10 ms，main 时钟代理 median 358.07 / P95 375.40 ms，均为合成快捷键往返代理。**未达到热启动 <300 ms 的研发目标**；冷启动未测。

单次 QSG 诊断中 show 请求约 76.85 ms、show 返回约 378.25 ms，约 301 ms 与 D3D11 设备创建日志同段，提示下一步应拆分该路径；这不是精确的驱动耗时归因，也不直接推断所有启动样本。

## 限制和下一步

macOS 按用户安排未执行。真实 JPEG/JPX 大扫描教材、真实跨屏拖动/触控板/高刷新率输入与 OS 呈现延迟未作完整人工验收；合成 raw 灰度样本不代表压缩图像峰值。后台 PDFium 单次调用不能抢占；过期结果丢弃不等于底层中断。超大页用动态分辨率，无分块，预算不足时可能暂时清空并重新渲染较低档页面。

CPU/GPU 模型预算不含 PDFium 内部缓存和驱动开销；系统 GPU 与进程内存单独报告。没有发行打包/许可闭环、密码输入、文字选择、标注或保存导出。下一阶段为原生 PDF 文字选择和复制，须获得进一步授权；本轮不会自动进入阶段 4。
