# 选择框点选标记与打字工具设置（2026-11-23）

## 使用

- **选择框**：自动或打字模式下，鼠标移到教材印刷的方框（“□ le sport”）上会出现浅色提示，单击即在框内画上标记，再次单击取消。标记是普通笔迹：随撤销/重做、橡皮擦、自动保存和 PDF 导出一起工作，不需要新的存储格式。颜色取打字工具的默认文字颜色，线宽随方框大小（约边长 14%，0.8–2.5 pt）。
- **✓ 还是 ✗**：默认“按语言”——法语、德语、西班牙语、意大利语习惯在方框里打叉（cocher / ankreuzen），英语和中文习惯打勾。判断顺序：本页文字层或已完成的 OCR 文字里的常见功能词与重音字母（法/德/西/意 vs 英语），否则大段汉字视为中文，再否则用文档的 OCR 语言（默认法语 → ✗）。打字工具设置里可以固定为 ✓ 或 ✗。
- **打字工具设置**：选中“打字”（T）后，右上角与画笔相同位置出现“文字 · N px”按钮和设置面板：6 个常用颜色 + 自选、字号滑块（8–36 px；选中文字的浮窗仍可到 72）、默认加粗/倾斜、预览，以及选择框标记方式。设置只影响新建答案，并保存在书架数据（`library-v1.json` 的 `textColor`、`textBold`、`textItalic`、`checkMark`）中，重启后保留。字体为随附的答案字体组（字母 Langlern Sans / Andika，汉字 Langlern Kai / 霞鹜文楷，见 `third_party/DEPENDENCIES.md`），导出时嵌入同样的字体，因此面板只显示不提供切换。

## 实现

`src/pdf/checkboxes.cpp` 只看渲染图像（目标教材是没有文字层的纯扫描件）：

1. 每页用 **固定 2.7 px/pt** 的专用渲染检测，与当前缩放无关；结果按页保存在 `ReadingModel` 的独立小表里（不随像素缓存淘汰），文档会话内每页只检测一次。专用渲染在显示帧发出**之后**进行，作为单独的 `boxesOnly` 帧送回，所以不会推迟页面显示；后来的请求不会作废它（结果与 revision 无关）。
2. 最暗通道 < 165 视为墨迹（彩色描边也算），8 连通域。
3. 候选：边长 5.5–22 pt、宽高比 ≤ 1.15、四边各 ≥ 86% 有描边、内部（内缩 20%）墨迹 ≤ 3%、整体填充 ≤ 62%、左右各留出 ≥ 20% 边长的空白。
4. 排除汉字“口”：近邻（< 0.8 个边长）若是比方框更高、上下都超出且密度 ≥ 16% 的字形则不是方框；方框正下方有零散笔画（“只”“识”的两点）也排除，但下面紧挨的另一个方框（整条上边）允许。

## 验证（macOS Apple Silicon，Qt 6.8.3，Release）

用户截图所在页（你好法语2学生用书 p.51，“Ses goûts”等）20 个方框全部识别、无误报。四本本机教材逐页调查（`realTextbookCheckBoxScan`，按需开启）：

| 教材 | 页数 | 方框 | 说明 |
| --- | ---: | ---: | --- |
| 你好法语3学生用书 | 153 | 2 | p.34 “oui / non”；正文汉字“口/只/识”误报已排除 |
| 你好法语3练习册 | 66 | 142 | 带阴影的 ❑ |
| 你好法语2学生用书 | 207 | 55 | p.51、53、85（倾斜扫描）、119（浅蓝底纹） |
| 你好法语2练习册 | 98 | 431 | 表格中成列的方框、浅灰方框 |

显示宽度 800 px 与 1400 px 的逐页结果完全一致。各页命中区域已人工看过联系图，没有发现误报；漏检没有逐页人工标注，不能给出召回率。专用渲染加检测约 25–50 ms/页（单次，最大约 0.25 s 含页面解码），在 PDF 工作线程，不阻塞界面。

自动测试（`annotation` 套件）：`checkBoxFixtureDetection`（`tools/make-checkbox-fixture.py` 生成的 MIT 样例：6 个真方框、实心块/已打叉/30 pt 大框/表格/3 pt 小框全部排除，旋转 90° 页，600/1200/2000 px 结果相同）、`checkBoxMarkToggleAndHistory`、`checkMarkFollowsLanguage`、`checkBoxClickAndTypingDefaults`（真实窗口：悬停提示、单击标记/取消、Ctrl+Z、标记不触发 PDF 重新渲染、设置面板改颜色/加粗/标记方式后新答案生效并写入书架文件），`realTextbookCheckBoxes`（固定真实教材 p.34 在 700/1500 px 两个宽度、p.20/p.78 汉字页无误报；练习册 p.14 为 14 个；配置 `LANGLERN_LARGE_PDF` 为你好法语2学生用书时 p.51 为 20 个）。

## 局限

- 启发式：圆形选项（○）、虚线框、手写体方框、与文字粘连或倾斜很大的方框可能漏检；与方框形状相同的其他符号可能误报。未识别处仍可用画笔手动标记。
- 语言判断依赖页面文字；扫描页在没有 OCR 结果时使用文档 OCR 语言设置（默认法语）。
- Windows 本轮未构建、未测试。
