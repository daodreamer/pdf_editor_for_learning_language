# LinguaPDF 设计稿适配

设计基准：仓库根目录 `LinguaPDF 学习原型.html`（用户于 2026-10-16 指定）。该次指令授权在既有阶段 8 上继续迭代，并明确接受新增本地开源依赖，所有功能保持离线。HTML 仅作为设计与交互规格，不作为桌面运行时。

## 页面及数据契约

- 书架：220 px 侧栏、56 px 标题区、继续阅读卡片、练习册网格、导入入口。内容来自实际打开成功的本地文档，保存路径、页数、阅读位置，不复制原型的六本示例教材。
- 阅读：52 px 顶栏、196 px 页面/书签侧栏、居中页面、六种工具、模式提示、笔色/粗细浮层。沿用虚拟阅读模型和 PDFium 专用线程；缩略图只复用有界缓存中的真实页面，未渲染页面明确显示页码。
- 生词本：列表与复习卡分栏，全部/待复习/新加入筛选、原文来源、显示释义、忘了/模糊/记住了。用户摘录与释义保存在本地，不内置假词典结果。
- 导入：文件预览和右侧选项。原型中的 OCR 定时器、CSS 扫描效果不算真实识别或修复，需由真实离线服务替代。

主题使用原稿 light/paper/dark 色值；布局提供侧栏/专注/练习面板，工具栏提供顶部/悬浮/侧边。保留系统窗口边框及 Windows/macOS 的真实窗口控件，不在 Windows 绘制假的 macOS 红黄绿按钮。

## 实施依赖顺序

1. 设计色值、组件、页面框架；迁移已有打开/阅读/标注/保存/导出，保留线程和坐标边界。
2. 本地书架、书签、生词和复习；保存失败可见，拒绝以示例计数填充界面。
3. 导入与离线服务；先确认可用引擎、模型和许可证，再接识别/查词/朗读/音频。
4. 真实 Windows 构建、既有回归、页面截图；macOS 实机及新性能 A/B 单独记录，未执行不计通过。

WorkspaceState 负责书架、词卡与 UI 偏好，不接触 PDFium 句柄；ShellState 负责当前文档和阅读状态，仍是唯一通向 PDF 专用 worker 的入口。练习答案继续使用现有原子 sidecar 与导出流程，书架导航不清空当前文档。

验收须对四页及空状态逐项检查，不能仅凭颜色相似宣布全稿功能完成。具体本轮结果与差异在本文件末尾更新。

## 与完整原稿仍有差距

这些项目仍未完成，不能据上述局部结果宣称原稿全部功能一比一交付：

1. OCR目前按当前页显式执行，结果在内存中；未提供整书OCR持久化队列、可检索文字层写回或全书识别进度。
2. 目前只有英汉/英文词库；日语、德语、法语等离线词典、完整词形处理和离线整句翻译模型尚未接入。原句朗读可用，逐词同步高亮尚未实现。
3. 批改可循环正确/错误/清除并随答案联动；没有自动判断对错，也没有原稿错误后自动弹出的专用订正框，可用打字工具手动添加订正。
4. 扫描优化为基础图像处理，拉直限制±3°，不包含页面曲面展开；裁边为亮度启发式，不保证所有教材不误裁。原件保持不变。
5. 音频支持本地文件、播放/暂停、跳转、系统支持的变速及约300ms轮询A–B循环；没有从教材自动提取音轨/波形或跨文档音频关联。
6. 书架暂未实现原稿的语言分类标签，书签暂为页码列表；部分历史后端状态消息仍是中文。中英文主界面可切换。
7. macOS的OCR/语音/音频本机后端与所有新功能的实机验证待后续平台实施；尚未执行本轮长时间真实教材滚动/显存压力复测。许可未决项见 third_party/DEPENDENCIES.md，不宣称公开发行整体合规。

下一步按上述差异补齐全书OCR数据契约和队列，再接离线翻译/多语词典与朗读高亮；继续以该HTML为唯一用户界面设计基准，不另行替换设计方向。
