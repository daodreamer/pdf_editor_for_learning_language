# 离线 OCR、选文与朗读

## 使用方式

- 自动模式：单击空白输入、单次按住拖动书写；双击左键的第二次按住拖动选择页面文字。双击不拖动选整词。点击已识别原文仍可查词，等待系统双击间隔后打开，以兼容双击手势。
- 点读模式：直接拖选原生/OCR 文字；扫描页仅按需识别当前可见页。
- 文本框内部：TextEdit 保持普通左键拖选和键盘选择，格式工具条加入复制、朗读；操作不转移编辑焦点、不改选区、不提交 IME。
- 页面选区：浮层提供复制、朗读、查词；Ctrl/Command+C 保持有效。
- “··· → OCR 与朗读设置”：法语（默认）、英语、简中、法英组合；可显式识别整页或框选区域。区域识别后自动选中该区域文字；随后点击区域外会重新取得该页文字层。
- 朗读使用系统实际可用的本地声音，可设置语言、声音和 0.5–2 倍语速，支持暂停/继续/停止。缺少声音时明确提示，短选文不自动猜语言，长选文分段播放，不静默截断。更换文档/关闭窗口停止朗读。

## 实现与预算

PDFium 唯一专用线程先读取原生字符；原生文字存在时优先使用。空文字扫描页或显式 OCR 请求在该线程生成不含应用答案/笔迹的底图，宽度目标 2400、最多 32 MiB，仍受 8192 边长约束。独立低优先级 OCR 线程接收不可变 QImage，灰度识别得到符号边界、词间空格、换行和阅读顺序。结果转换回归一化页面显示坐标，共用 TextSelection/SelectionItem；缩放不重新识别。

单页最多 65536 个字符，页面文字总预算沿用 16 MiB。OCR 待执行图像使用单槽替换，任一时刻最多一个执行任务和一个待办快照。会话和语言修订双重检查拒绝旧结果。Tesseract 识别阶段使用 ETEXT_DESC 的取消回调和 30 秒期限；初始化、版面分析和第三方内部调用不能保证立即打断。正常关闭异步等待 PDF/OCR 两线程结束后退出，析构仅作兜底。模型通过 QFile 读取，覆盖 Windows 中文路径。

结果缓存位于应用 CacheLocation/ocr-v1，隔离验收时位于 LANGLERN_WORKSPACE_DIR/ocr-v1。键包含原 PDF SHA-256、页码、Tesseract 版本、模型内容散列、语言、输入尺寸和识别区域。原子写入 JSON，单文件上限 8 MiB，最多 256 条/128 MiB，按修改时间淘汰；读取失败或无效时重识别。缓存是可删除的学习辅助结果，不写回 PDF，不混入答案快照或 PDF 导出。没有全书后台识别。

## 依赖与离线边界

锁定来源、源码 tarball/模型 SHA-256、模型提交及通知文件散列见 `third_party/ocr.lock.json`。`tools/bootstrap-ocr.py` 只在开发准备/构建时获取固定产物；应用没有网络下载逻辑。

| 依赖 | 用途 / 构建 | 许可证据 |
| --- | --- | --- |
| Tesseract 5.5.1 | LSTM 符号级 OCR，静态库；关闭 curl/archive/OpenMP/训练工具/旧引擎/调试字体，使用运行时 CPU 检测 | `third_party/notices/ocr/Tesseract-LICENSE.txt`，Apache-2.0 |
| Leptonica 1.85.0 | 像素分析、阈值等；关闭 GIF/JPEG/TIFF/WebP/OpenJPEG | `Leptonica-license.txt`，BSD 两条款 |
| libpng 1.6.58 / zlib 1.3.2 | Tesseract 内部图像缓冲需要的 PNG/压缩；静态库，不新增运行时 DLL | `libpng-LICENSE.txt` / `zlib-LICENSE.txt` |
| tessdata_fast | 法/英/简中，合计约 7.35 MiB；固定提交 `87416418657359cb625c412a48b6e1d6d41c29bd` | `tessdata_fast-LICENSE.txt`，Apache-2.0 |
| Windows SAPI | 枚举本机实际可访问声音及 LCID，不将法语匹配为英语 | 系统组件，不复制系统声音包 |

原先尝试完全禁用图像编解码库，真实测试发现 Tesseract 内部图像序列化仍使用 PNG，产生大量降级告警；最终保留 libpng/zlib，并关闭无用的 TIFF 调试字体。没有通过隐藏错误冒充依赖完整。所有通知随 Windows 候选包复制；没有据此声明整个产品发行已合规，Qt/PDFium/词库等既有待审项仍在。

## 验证方法与限制

构建：`tools/build-windows.ps1 -Test -Lint` 自动准备锁定 OCR 依赖。`ocr_selection_tests` 验证真实引擎的法语重音字符、半词选择、磁盘缓存、中文模型目录、缺模型、请求失效、自动模式双击/普通拖动、文本框拖选/焦点/复制/朗读/撤销，以及系统声音状态。没有声音/音频设备的平台明确跳过实际语音测试。

固定真实教材使用 AGENTS.md 的本机 PDF 或 LANGLERN_REAL_PDF；第 34 页检查实际识别、双击选文/复制、整词选择、局部区域坐标、缩放复用、切换文档旧结果拒绝及原文件前后 SHA-256。CI 不含教材时明确 skipped。`benchmarks/run-ocr.py --run benchmarks/results/<全新目录> --repeat 3` 保存独立进程日志、窗口图、文字及进程内存采样；教材和提取内容均不提交仓库。

OCR 可能有错字、标点/大小写变化、多栏顺序错误；区域识别可限制阅读范围，不承诺还原教材语义或手写识别。Windows SAPI 只能使用其实际枚举到的声音，系统设置显示的其他语音引擎声音不一定可用。macOS OCR 源码构建、Metal 交互及本地朗读尚未实机验收；没有执行 sanitizer、冷启动、GPU 显存或完整呈现帧测量。
